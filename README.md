# Офис сървър

Файлов сървър за малкия офис: SMB споделяне `Office` (диск O:), SQL Server Express, уеб портал "Офис портал" (HTTPS през Caddy), нощен архив в 23:00.

## Папки
- `portal\` - уеб порталът (FastAPI), виж `portal\README.md`
- `scripts\` - инсталационни скрипти за сървъра
- `client\` - файлове за компютрите на хората, виж `client\ИНСТРУКЦИЯ.md`
- `logs\` - логове и `backup-status.json`

## Инсталация на сървър лаптопа
1. Разархивирай всичко в `C:\OfficeServer`.
2. Двоен клик на **INSTALL-SERVER.cmd** (иска администраторски права, пита за името на сървъра). При преименуване иска рестарт и се пуска отново.
3. В края показва адрес и парола за администратора. Нататък хората се създават от портала ("Потребители"): порталът създава и Windows профил със същата парола.

Стъпка по стъпка (ако нещо се счупи): `scripts\phase0-check.ps1`, `phase1-server.ps1`, `install-python.ps1`, `phase2-share.ps1`, `phase4-portal.ps1`, `phase5-backup.ps1 -BackupDrive E:`. SQL Server Express (по желание): инсталирай го, после `phase3-sql-net.ps1`.

## Права
Няма/четене/запис по папка, от страницата "Потребители". Порталът ги слага и върху самите Windows папки (NTFS), така че важат и в диск O:. Папките, които човек няма право да отваря, дори не се виждат там.
- Порталът създава Windows профил със същото име и парола при "Създай потребител" (и сменя паролата при нулиране). Ръчно `net user` не трябва.
- `NTFS_RIGHTS=1` е в `portal\.env`. Да се приложат всички права наново: `python -m app.cli sync-rights`.
- Правата се прилагат при запис от страницата. Нова основна папка е отворена за всички, докато не ѝ се зададат права.
